# wedding-map

서울 결혼식 장소(웨딩홀 · 장로교회 · 서울시 공공예식장) 정적 지도. 개인 결혼 준비용 비상업 페이지.

- 출처: 한국소비자원 참가격(결혼서비스 가격공개), 서울시 공공예식장(더 아름다운 결혼식), 아이웨딩·웨딩북·다이렉트 표기가(각 링크), 교회 홈페이지 결혼예식 안내
- 가격은 각 출처에 표기된 값을 그대로 옮긴 것입니다. 출처별 수집일과 참가격 공개일은 페이지 하단과 각 가격표 아래에 표시됩니다. 실제 견적은 업체에 직접 확인해 주세요.
- 정보 수정·삭제 요청은 이 저장소의 [Issues](https://github.com/Seungjun-bob/wedding-map/issues)로 남겨 주세요. 요청이 오면 바로 반영합니다.
